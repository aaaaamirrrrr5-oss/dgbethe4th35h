3) هشدارها و محدودیت محیط
- WARN: Gradle Wrapper اجرایی و gradle-wrapper.jar در ورودی موجود نیستند.
- `gradle` در PATH نصب نیست.
- ANDROID_HOME و ANDROID_SDK_ROOT تنظیم نشده‌اند و Android SDK در دسترس نیست.
- تلاش مستقل kotlinc برای MainActivity.kt با exit code غیرصفر و خطاهای unresolved reference متوقف شد، چون Android SDK، Compose و classpath کامل ماژول‌ها به آن داده نشده‌اند. این فقط بررسی parser بدون تشخیص خطای نحوی بود؛ compile یا type-check موفق محسوب نمی‌شود.

4) تست‌هایی که اجرا نشده‌اند و نباید PASS تلقی شوند
- Android Gradle compile و Compose compiler.
- `:app:testDebugUnitTest` و تمام تست‌های Gradle/JUnit نسخه جاری.
- Android lint و static checks وابسته به Gradle.
- `assembleDebug` و `assembleRelease`.
- امضای release، verify امضا، نصب، به‌روزرسانی از نسخه قبلی و اجرای APK.
- بررسی UI روی شبیه‌ساز/گوشی، RTL عملی، TalkBack، font scale، چرخش صفحه و رفتار بازگشت/بازیابی state.
- عملکرد واقعی روی میزبان مجاز، شبکه قطع، DNS failure و بررسی مصرف RAM/CPU/battery.
- تست‌های v0.8.0 در بسته ورودی تاریخچه‌اند و در این اجرای v0.9.0 دوباره اجرا نشده‌اند.

5) تغییرات v0.9.0
- داشبورد، هدر برند، وضعیت فعالیت و کارت‌های آماری ارتقا یافتند؛ تم مشکی/قرمز و چهار مقصد Bottom Navigation حفظ شدند.
- نتایج وب، تحلیل سورس و تحلیل ZIP در فهرست واحد ادغام شدند؛ موارد با کلید شناسه/دارایی/محل دقیق تکراری حذف شدند.
- جست‌وجوی متن و فیلتر شدت به بخش یافته‌ها افزوده شد؛ آمار داشبورد از یافته‌های یکپارچه استفاده می‌کند.
- جزئیات تخصصی پرتراکم به‌صورت باز/بسته شونده نمایش داده می‌شوند؛ پنل‌ها و داده‌ها حذف نشده‌اند.
- خروجی JSON به schema_version=3 و version=0.9.0 ارتقا یافت و فهرست یافته‌های یکپارچه را در سطح اصلی نگه می‌دارد؛ فراداده نسخه HTML نیز به‌روز شد.
- ماتریس 40 حوزه، گزارش اجرای پنج مرحله، release notes و آزمون‌های پذیرش دستی اضافه شدند.

6) ریسک باقیمانده
- ریسک اصلی تحویل: build واقعی Android هنوز در محیط دارای Gradle 8.9، JDK 17، Android SDK Platform 35 و Build Tools 35.0.0 اجرا نشده است.
- تا عبور CI/Android Studio از compile، unit test، lint و assemble، این نسخه را APK آماده نصب یا release تأییدشده تلقی نکنید.
- تحلیل rule-based و ایستا است؛ نبود یافته معادل امن بودن نیست. مسیرهای DAST، AST/taint، runtime integration و برخی حوزه‌ها طبق ماتریس هنوز جزئی/پشتیبانی‌نشده‌اند.
- عملیات پرریسک و تغییر خودکار روی production، سفارش/پرداخت/مشتری/موجودی اضافه نشده است؛ اصلاحات همچنان preview/plan هستند.
