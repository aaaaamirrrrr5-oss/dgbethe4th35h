# NEXUS CYBER AI — Prompt Pack
این بسته شامل ۲۲ فایل TXT ماژولار است.
ترتیب پیشنهادی اجرا:
1. ابتدا 00_MASTER_EXECUTION_PROMPT.txt
2. سپس 01 تا 03 برای معماری و هسته محلی
3. فایل‌های 04 تا 16 برای موتورهای امنیتی
4. فایل‌های 17 تا 20 برای تجربه کاربری، سیاست امنیتی، QA و انتشار
